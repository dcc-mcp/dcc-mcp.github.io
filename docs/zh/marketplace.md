# 搜索软件包目录

[DCC-MCP Marketplace](https://github.com/dcc-mcp/marketplace) 收录 Skills、资产提供方、工作室集成与共享基础设施。选择目标 DCC 后，可以复制配置提示词或准确的 CLI 命令。

官网不会安装软件。你确认后，`dcc-mcp-cli marketplace install ... --reload` 会安装所选包 ID 并重新加载 DCC。不熟悉的软件包应先检查。
