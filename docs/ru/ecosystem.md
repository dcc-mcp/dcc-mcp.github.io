# Каталог проектов DCC-MCP

В каталоге собраны инструменты для создания цифрового контента (DCC) и автоматизации работы в творческих приложениях. Начните с [общедоступного Skill dcc-mcp](https://clawhub.ai/loonghao/skills/dcc-mcp), затем выберите адаптер или расширение для своей задачи. В репозитории проекта описаны установка, совместимость и API приложения. Документация Core охватывает общую инфраструктуру подключения и вызовов. У типизированного инструмента определены параметры, их типы и результат, поэтому вызов можно проверить.

## Общая инфраструктура и инструменты для совместного использования

- [dcc-mcp-core](https://github.com/dcc-mcp/dcc-mcp-core) – Общий шлюз, интерфейс командной строки, средства выполнения операций через API MCP/REST, функции безопасности, диагностики и наблюдения за процессами.
- [dcc-mcp-runtime](https://github.com/dcc-mcp/dcc-mcp-runtime) – Общий интерфейс выполнения программ на Python, а также контракт, используемый для внешних адаптеров DCC-MCP.
- [Поиск на рынке](/ru/marketplace) – это поиск в официальном каталоге расширений, используемом инструментом `dcc-mcp-cli`; [источник каталога](https://github.com/dcc-mcp/marketplace).
- [dcc-mcp-fpt](https://github.com/dcc-mcp/dcc-mcp-fpt) – Интеграция с программой Autodesk Flow Production Tracking.
- [fpt-cli](https://github.com/dcc-mcp/fpt-cli) – Интегрированный инструмент для автоматизации работы с данными в языке Rust, предназначенный для использования в системе Autodesk Flow Production Tracking.
- [dcc-mcp-openusd](https://github.com/dcc-mcp/dcc-mcp-openusd) – Рабочие процессы и форматы обмена данными OpenUSD.
- [dcc-materialx](https://github.com/dcc-mcp/dcc-materialx) – Интернет-площадка для обмена материалами в рамках проекта MaterialX.
- [dcc-lookdev](https://github.com/dcc-mcp/dcc-lookdev) – Стандартизированные процессы разработки визуальных элементов для различных форматов данных.
- [dcc-modeling-spec](https://github.com/dcc-mcp/dcc-modeling-spec) – Спецификации для нейтральной моделирования, версия 2. Эти спецификации предназначены для использования в процессах моделирования в программах Maya, Blender, Houdini и 3ds Max.
- [dcc-pipeline-publish](https://github.com/dcc-mcp/dcc-pipeline-publish) – Программы для публикации данных в форматах DCC, USD, а также для отслеживания процессов обработки данных.
- [dcc-texture-pipeline](https://github.com/dcc-mcp/dcc-texture-pipeline) – Детерминированные процессы обработки текстур с использованием технологий OpenImageIO и OpenColorIO.
- [dcc-itchio](https://github.com/dcc-mcp/dcc-itchio) – Навыки безопасного приобретения активов из itch.io и публикации игр после их готовности к релизу.
- [dcc-media-enhance](https://github.com/dcc-mcp/dcc-media-enhance) – Оркестровка задач в языке Rust, основанная на принципе использования агентов. Предназначена для удаления шумов и улучшения качества изображений с помощью уже имеющихся бэкендов.
- [dcc-mcp-cache-inspector](https://github.com/dcc-mcp/dcc-mcp-cache-inspector) – Независимая инструментальная утилита для проверки кэш-памяти в офлайн-режиме. Не требует использования каких-либо адаптеров или пакетов из PyPI.
- [mcpcall](https://github.com/dcc-mcp/mcpcall) – это CLI-интерфейс для вывода и вызова инструментов сервера MCP через стандартный ввод/вывод или HTTP-протокол Streamable.
- [dcc-mcp-renderdoc](https://github.com/dcc-mcp/dcc-mcp-renderdoc) – Инструмент для захвата данных процесса отрисовки и его последующего воспроизведения.
- [dcc-mcp-tracy](https://github.com/dcc-mcp/dcc-mcp-tracy) – Методика захвата и анализа данных с использованием инструмента Tracy Frame-Profiler.

## DCC и адаптеры для творческого применения

Чтобы управлять приложением с помощью естественного языка, начните с [руководств по приложениям и примеров запросов](/ru/use-cases). Условия установки и особенности конкретной программы приведены в репозитории её адаптера.

В подписанном удаленном каталоге, проверенном официальной версией CLI 0.20.39, указано 38 идентификаторов адаптеров. Установка каталога возможна для 33 из этих адаптеров. Для таких адаптеров, как `kdenlive`, `material-maker`, `powerpoint`, `tiled` и `wwise`, информация о том, что установка каталога невозможна, указана как `catalog_install_available=false`. Однако определение каталога или отдельная версия адаптера не означает, что соответствующий адаптер может быть использован в реальных условиях или принят для производственного использования.

- [3ds Max](https://github.com/dcc-mcp/dcc-mcp-3dsmax) – Autodesk 3ds Max.
- [3D Slicer](https://github.com/dcc-mcp/dcc-mcp-slicer) – позволяет работать с синтетическими объектами, фантомами материалов, а также с мешками сферической формы. Предусмотрены возможности экспорта данных в форматах NRRD/STL, обработки сценок для МРТ-обследований, настройки камеры и параметров срезов, а также отображения данных в формате PNG. Используются только синтетические данные; не поддерживается импорт данных пациентов из формата DICOM, клиническая информация, а также загрузка произвольных сценок. Источник данных сохраняется на сервере Core версии 0.20.41. Необходимо провести дополнительную проверку для использования данного источника. В каталоге не указан адрес адаптера; проверка производится с помощью CLI версии 0.20.39.
- [After Effects](https://github.com/dcc-mcp/dcc-mcp-aftereffects) – программа от компании Adobe.
- [AutoCAD](https://github.com/dcc-mcp/dcc-mcp-autocad) – Портативное средство автоматизации работы с файлами формата DWG с использованием протокола COM, а также программы `accoreconsole.exe`. Необходимо проверить доступность и процесс установки этого средства в соответствующем репозитории.
- [Blender](https://github.com/dcc-mcp/dcc-mcp-blender) – это дополнение к программе Blender, а также сервер, который может использоваться внутри самой программы Blender.
- [CapCut](https://github.com/dcc-mcp/dcc-mcp-capcut) – Это программа для обработки изображений. Для её использования необходимо иметь аутентифицированный локальный сервер.
- [Cinema 4D](https://github.com/dcc-mcp/dcc-mcp-cinema4d) – Программа для работы с документами без использования головок управления, а также для автоматизации процессов преобразования и отображения изображений.
- [ComfyUI](https://github.com/dcc-mcp/dcc-mcp-comfyui) – функции валидации контрактов в реальном времени, выполнения операций в ограниченном количестве элементов и получения артефактов. Руководство по использованию [ComfyUI MCP](/ru/control/comfyui) описывает интерфейс игры, поддерживает форматы изображений PNG и GLB, а также форматы PBR. В руководстве также рассматривается вопрос о доступности исходного кода по сравнению с релизированным продуктом.
- [Программа запуска игр Epic Games и Fab](https://github.com/dcc-mcp/dcc-mcp-epic) — независимо выпущена версия v0.2.1 ([источник выпуска](https://github.com/dcc-mcp/dcc-mcp-epic/tree/1157defe203aab4beaa8f7be56f8063caac2a415)) для инвентаря установленных движков, проверки проектов и операций, связанных с базовыми поставщиками; не является идентификатором адаптера, проверяемого CLI 0.20.39. Установка движка остается только плановой без проверенного нативного поставщика; вход в систему, процедура CAPTCHA, покупки и принятие лицензии все еще осуществляются человеком. См. [Руководство по управлению Epic Games](/ru/control/epic-games).
- [FreeCAD](https://github.com/dcc-mcp/dcc-mcp-freecad) – параметрическое моделирование в CAD-программе, проверка топологии и обмен многочленными сетками.
- [Gaea](https://github.com/dcc-mcp/dcc-mcp-gaea) – Независимо выпущенная версия 0.1.1 ([источник выпуска](https://github.com/dcc-mcp/dcc-mcp-gaea/tree/b95d3f81b8f883732c73d268658100d09d9cad84)). Она позволяет выполнять типовые задачи по созданию ландшафтов и проверке результатов их выполнения. Это не является идентификатором адаптера, который проверяется через CLI 0.20.39. Работы с лицензированными проектами, отмена процессов, качество ландшафтов, а также импорт данных из Unreal Engine все еще не проверены. См. [Руководство по использованию Gaea](/ru/control/gaea).
- [GameMaker](https://github.com/dcc-mcp/dcc-mcp-gamemaker) – адаптер для работы с GameMaker. Это не идентификатор адаптера, который указан в каталоге, проверенном при использовании CLI 0.20.39.
- [GIMP](https://github.com/dcc-mcp/dcc-mcp-gimp) – GIMP 3.
- [Godot](https://github.com/dcc-mcp/dcc-mcp-godot) – это движок для создания 2D-игр, а также инструменты для авторизации игр.
- [Houdini](https://github.com/dcc-mcp/dcc-mcp-houdini) – SideFX Houdini.
- [Иллюстратор](https://github.com/dcc-mcp/dcc-mcp-illustrator) – предназначен для редактирования документов в формате Adobe Illustrator, векторных изображений, а также для вывода результатов работы.
- [Inkscape](https://github.com/dcc-mcp/dcc-mcp-inkscape) – Интеграция источника информации в систему, которая не была проверена с помощью CLI 0.20.39. Процесс производства на платформе Cloud MCP все еще остается заблокированным из-за проверки происхождения информации; см. [документ с записями о тестировании Cloud](/ru/cloud-agents#cloud-mcp-tests).
- [Katana](https://github.com/dcc-mcp/dcc-mcp-katana) – Производитель: Foundry Katana.
- [Kdenlive](https://github.com/dcc-mcp/dcc-mcp-kdenlive) — предназначен для создания проектов, отображения изображений с использованием технологии MLT, а также для управления редактором DCC-CUA. В репозитории уже выпущена версия 0.1.1 ([источник выпуска](https://github.com/dcc-mcp/dcc-mcp-kdenlive/tree/376c812047b308239174aa1bbb662da1908f829e)); в каталоге, проверенном с помощью CLI 0.20.39, указано, что версия `kdenlive` составляет 0.1.0, при этом параметр `catalog_install_available=false` отображается. Эта проверка каталога не включала проверку работы редактора и процесса отображения. Подробнее смотрите [руководство по управлению Kdenlive](/ru/control/kdenlive).
- [KiCad](https://github.com/dcc-mcp/dcc-mcp-kicad) – это программа для работы с платками в KiCad 9. Она использует нативный API `pcbnew` и функциональность `kicad-cli`. Программа управляет процессом создания платок самостоятельно, без необходимости использования сервера PCB Editor или других средств управления. Источник кода закреплен в версии Core и сервера 0.20.41. Нет плана по выпуску новой версии программы. Также в каталоге нет информации о поддерживаемых адаптерах по версии 0.20.39.
- [Krita](https://github.com/dcc-mcp/dcc-mcp-krita) – Krita.
- [LiquiGen](https://github.com/dcc-mcp/dcc-mcp-liquigen) – Инструмент для проверки графа узлов, управление процессом симуляции, экспорт данных в формате VAT, а также передача данных через Unreal Engine. Этот инструмент указан как `liquigen` в каталоге, проверенный с помощью CLI 0.20.39.
- [Mari](https://github.com/dcc-mcp/dcc-mcp-mari) – проекты от компании Foundry, геометрия объектов, графические элементы, процесс разработки дизайна, а также возможность экспорта текстур.
- [Создатель материалов](https://github.com/dcc-mcp/dcc-mcp-material-maker) – это сервис для создания процедурных материалов. В каталоге, проверенном с помощью CLI 0.20.39, указана версия 0.3.1; при этом параметр `catalog_install_available=false`.
- [Maya](https://github.com/dcc-mcp/dcc-mcp-maya) – Autodesk Maya.
- [Marmoset Toolbag](https://github.com/dcc-mcp/dcc-mcp-marmoset) – инструмент для создания материалов формата PBR, проверки сцен и их рендеринга.
- [Marvelous Designer](https://github.com/dcc-mcp/dcc-mcp-marvelous-designer) – Независимо выпущенная версия v0.1.1 ([источник выпуска](https://github.com/dcc-mcp/dcc-mcp-marvelous-designer/tree/4d4d289905f82290804b288d03d84d541b01af08)). Предусматривает возможность ввод данных для создания одежды, моделирование процессов производства, сохранение и экспорта данных. Не является адаптером для каталога, который проверяется с помощью CLI 0.20.39. Возможности использования лицензируемых компонентов, таких как Qt Bootstrap, моделирование тканей и передача управления процессом производства, ещё не полностью реализованы. См. руководство по использованию [Marvelous Designer](/ru/control/marvelous-designer).
- [MotionBuilder](https://github.com/dcc-mcp/dcc-mcp-mobu) – Autodesk MotionBuilder.
- [Nuke](https://github.com/dcc-mcp/dcc-mcp-nuke) – Это программа от компании Foundry.
- [OBS Studio](https://github.com/dcc-mcp/dcc-mcp-obs) – инструмент для проверки сценариев и источников звука, а также для управления записью данных. Этот инструмент указан как `obs` в каталоге, проверенном с помощью CLI 0.20.39. Установка адаптера не приводит к установке самого OBS Studio.
- [Офис](https://github.com/dcc-mcp/dcc-mcp-office) — общий путь использования приложения `office`: протокол office-rpc/1, сторонний модуль на языке C# COM, работа с форматом Open XML, соединение с Microsoft Graph, а также навыки, общие для всей серии Office-приложений. Этот общий путь отличается от 38 идентификаторов адаптера, указанных в CLI 0.20.39; наличие приложений, специфичных для конкретного адаптера, остается за этим адаптером.
- [PowerPoint](https://github.com/dcc-mcp/dcc-mcp-powerpoint) – Процесс создания презентаций на основе данных из Deck IR, с использованием формата Open XML. Каталог, проверенный с помощью CLI 0.20.39, содержит информацию о версии 0.1.0; при этом параметр `catalog_install_available=false`.
- [Word](https://github.com/dcc-mcp/dcc-mcp-word) – документы формата Word, поля для ввода данных, а также механизм перемещения текста по странице. Предполагается, что репозиторий адаптера все еще является лишь временным объектом, до его полного запуска еще далеко.
- [Excel](https://github.com/dcc-mcp/dcc-mcp-excel) – рабочие книги, формулы, диаграммы и панели управления процессами. Планируется их использование; репозиторий адаптеров все еще является временным объектом, который еще не был выпущен в полной степени.
- [Outlook](https://github.com/dcc-mcp/dcc-mcp-outlook) – это инструмент для создания черновиков писем и управления расписанием (планируется в третьей фазе; оценка: `host_limited`). Этот инструмент работает через MAPI/COM. Для его использования требуется согласие пользователя при первом запуске программы. Следовательно, у этого инструмента нет возможности работать без согласия пользователя. Он не подлежит проверке в процессе интеграции, а также освобожден от необходимости прохождения проверки. Использование пути, связанного с Microsoft Graph, является предпосылкой для проверки программы в процессе интеграции.
- [OpenSCAD](https://github.com/dcc-mcp/dcc-mcp-openscad) – Декларативная параметрическая CAD-верификация, предварительное отображение результатов работы программы, а также возможность экспорта многочленных сеток.
- [OpenScreen](https://github.com/dcc-mcp/dcc-mcp-openscreen) — Независимо выпущенная версия v0.1.1 ([источник выпуска](https://github.com/dcc-mcp/dcc-mcp-openscreen/tree/5a32837d9d1b3bd2aea04bf61e61b4a54bbd5262)), включает в себя операции ввода текста, `sources`, `record` и `export`; не является идентификатором адаптера, указанным в каталоге, проверяемом CLI 0.20.39. Тестирование источника не подтверждает пригодность реальной записи на Windows; неподдерживаемый выбор окна остается в ведении dcc-cua и ui-control. См. [Руководство по управлению контроллером OpenScreen](/ru/control/openscreen).
- [ParaView](https://github.com/dcc-mcp/dcc-mcp-paraview) – Постоянно используемые процессы обработки данных в формате ParaView: обработка данных с использованием определенных примитивов, создание срезов из плоскостей, выделение контуров, экспорт проверенных на качество данных, сохранение состояния процесса обработки данных, а также отображение данных в формате PNG. Источник данных закреплен в версии Core и сервере 0.20.41; необходимо провести повторную проверку функциональности этой версии. Никаких публикаций пока нет, а идентификатор адаптера не указан в каталоге, проверенный с помощью CLI 0.20.39.
- [PhotoCraft](https://github.com/dcc-mcp/dcc-mcp-photocraft) – Экспериментальный адаптер для официальной версии движка PhotoCraft 0.2.0. Этот адаптер не является частью какого-либо приложения; он также не открывает окна на рабочем столе. Он не указан в каталоге адаптеров, проверенном с помощью CLI 0.20.39.
