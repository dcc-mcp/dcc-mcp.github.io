# Примеры адаптеров и запросов

На каждой карте указаны выходные данные, репозиторий, которому принадлежит эта карта, а также команды для выполнения определенных действий. Агент, использующий навык [`dcc-mcp`](https://clawhub.ai/loonghao/skills/dcc-mcp), все равно должен обнаружить местные инструменты или пакеты из Marketplace, прежде чем устанавливать что-либо.

::: info Официальный выставочный каталог
<a href="https://dcc-mcp.github.io/showcase/" target="_self">Откройте коллекцию DCC-MCP Showcase.</a> Для полных данных, источников информации о проектах, записей о использовании соответствующих инструментов, а также информации о лицензиях. Примеры адаптера ниже сохраняют свою первоначальную структуру данных; некоторые карточки показывают возможности использования этих адаптеров, но они не являются записями о производстве или воспроизведении этих адаптеров в данной сессии.
:::
