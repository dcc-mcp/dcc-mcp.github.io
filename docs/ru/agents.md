# Установка и первое подключение агента

В [общедоступном Skill `dcc-mcp`](https://github.com/dcc-mcp/dcc-mcp-agent-plugins/tree/main/plugins/dcc-mcp/skills/dcc-mcp) описан порядок работы агента. Через `dcc-mcp-cli` можно проверить Gateway, найти инструменты, выполнить типизированные вызовы, диагностировать ошибки, обновить компоненты и установить пакеты из каталога.

Для первого подключения нужны CLI, Gateway и адаптер целевого приложения. Сверьтесь с [инструкцией по быстрому запуску](https://dcc-mcp.github.io/dcc-mcp-core/guide/getting-started), проверьте установленные компоненты и добавьте недостающие.

Выполните следующую команду в рабочем каталоге Codex, Claude Code, Gemini CLI, GitHub Copilot, Cursor, Windsurf, OpenCode, Cline, Roo Code, Kiro CLI, Amp или другого агента с поддержкой Agent Skills.

```bash
npx --yes skills@1.5.23 add dcc-mcp/dcc-mcp-agent-plugins --skill dcc-mcp
```

Для установки на уровне пользователя используйте параметр `--global`. Нужно запустить новую сессию агента, если хост обнаруживает навыки только при начале работы системы.

В разделе установки домашней страницы используется один и тот же список команд для выбора: Codex, Claude Code, Cursor, Gemini CLI, GitHub Copilot, Windsurf, OpenCode, Cline, Roo Code, Kiro, Amp, CodeBuddy, OpenHands, Continue, Replit, OpenClaw и WorkBuddy.

Пакет npm является опциональным. Используйте его, если необходимо использовать сервисы, предоставляемые поставщиками услуг или командой разработчиков, через каталог `node_modules`. Это подходит для ситуаций, когда необходимо работать в автономном режиме или при использовании пакетов для управления процессами.

```bash
npm install @dcc-mcp/skills
```

## Нативные рынки плагинов

Используйте рынок приложений, предоставляемый самой платформой Codex или Claude Code. Эти команды устанавливают тот же самый класс `dcc-mcp` из репозитория [`dcc-mcp-agent-plugins`](https://github.com/dcc-mcp/dcc-mcp-agent-plugins#install).

### Codex

```bash
codex plugin marketplace add dcc-mcp/dcc-mcp-agent-plugins
codex plugin add dcc-mcp@dcc-mcp
```

### Claude Code

```text
/plugin marketplace add dcc-mcp/dcc-mcp-agent-plugins
/plugin install dcc-mcp@dcc-mcp
```

Другие варианты установки нативных плагинов и реестров также описаны в официальном репозитории.

## Проверка первого подключения

```text
Подключись к Blender и сообщи имя файла открытой сцены, названия коллекций и количество объектов. Оставь сцену без изменений и укажи, какой экземпляр приложения и какой инструмент использовались.
```

## Агенты типа “Cloud” и DCC-MCP

Для информации о платформенных интерфейсах, списке программного обеспечения для облачных услуг, а также о версиях рабочих процессов смотрите документ [Cloud agents and DCC-MCP](/ru/cloud-agents). Шелл-агент может использовать командную оболочку и HTTP-гейт. Однако каждая приложение, адаптер и рабочий процесс все еще нуждаются в проверке в целевой среде. Сервисы DCC должны работать в режиме loopback. Для обеспечения безопасного доступа между сетями необходимо использовать протокол TLS и механизмы аутентификации. Плагин не включает в себя само программное обеспечение DCC или его лицензии.

## Следует поддерживать актуальность навыков и инструментов CLI.

Используйте обновитель, который используется при каждой установке. Агенты Skills, загружаемые с GitHub, используют файл `skills`.

```bash
# Update managed copies in this workspace.
npx --yes skills@1.5.23 update -p -y

# Update managed user-level copies.
npx --yes skills@1.5.23 update -g -y
```

Проверьте состояние DCC-MCP CLI отдельно. После этого применяйте проверенную обновление только при наличии согласия всех заинтересованных сторон.

```bash
dcc-mcp-cli update check
dcc-mcp-cli update apply
```

OpenClaw и прямые установки ClawHub используют собственные записанные исходные данные и команды обновления. См. раздел [Как поддерживать актуальность установленных навыков](https://github.com/dcc-mcp/dcc-mcp-agent-plugins#keep-installed-skills-current). Не добавляйте параметр `--force` для непосредственных обновлений; навыки, которые были закреплены или изменены локально, должны остаться без обновления.

## Используйте краткое напоминание.

Навыки включают в себя определенные процедуры, поэтому в указаниях к выполнению задачи достаточно указать только саму задачу и ее безопасные границы.

```text
Используйте навык dcc-mcp для выполнения задачи DCC. Прежде чем устанавливать или изменять состояние системы, обязательно проведите проверку. В конце представьте доказательства своей работы.
```

## Установляйте только те навыки, которые действительно необходимы вам.

| Намерение/Цель | Навыки |
| --- | --- |
| Проводите реальные операции с DCC-командами, изучайте различные инструменты и возможности расширений. | `dcc-mcp` |
| Создайте или модернизируйте полноценный адаптер/режим работы. | `dcc-mcp-creator` |
| Создайте или улучшите набор навыков, специфичный для DCC. | `dcc-mcp-skills-creator` |

Заменяйте значение `--skill` в универсальном команде только тогда, когда задание соответствует одной из двух возможных путей разработки.

## Искать, описывать и называть.

```bash
# Confirm the gateway and connected hosts.
dcc-mcp-cli health
dcc-mcp-cli list

# Search narrowly, then follow the returned next_step.
dcc-mcp-cli search --query "create sphere" --dcc-type maya

# Execute the returned tool slug with validated arguments.
dcc-mcp-cli call <tool-slug> --json '{"radius": 2.0}'
```

Не стоит догадываться о названиях инструментов или загружать все шаблоны бэкенда. Сначала проведите поиск, а затем выполните действия `load` или `describe`, указанные в `next_step`.

## Используйте ID запроса перед повторным попыткой.

Сохраняйте значение `request_id` из неудачной вызова. Используйте встроенный путь к данным в CLI.

```bash
dcc-mcp-cli doctor
dcc-mcp-cli stats --status failure
```

Затем можно найти файл `dcc_feedback__report` с помощью той же процедуры поиска. Необходимо просмотреть и скрыть информацию из отчета перед его распространением. Создание внешней проблемы все еще требует авторизации пользователя.
