# Интеграции с программами для творчества

DCC-MCP соединяет агенты AI с программным обеспечением для создания цифрового контента, которое уже используется вашей командой. Этот каталог соответствует каждому поддерживаемому приложению и его официальному репозитории адаптеров. Также указаны общие поисковые термины, которые используются людьми: **Maya MCP**, **Blender MCP**, **Houdini MCP**, **3ds Max MCP**, **Substance Painter MCP** и **SP MCP**.

Для управления подключенным DCC можно использовать официальный сайт [Skill](https://clawhub.ai/loonghao/skills/dcc-mcp). Чтобы найти дополнительные возможности для работы с процессами, можно воспользоваться сайтом [Skill Marketplace](/ru/marketplace). А для ознакомления с каталогом реализованных функций можно использовать инструмент [`dcc-mcp-cli dcc-types`](https://dcc-mcp.github.io/dcc-mcp-core/guide/cli-reference).

## Распространенные запросы типа DCC MCP

### Есть ли такой курс, как Maya MCP?

Да. Официальная интеграция [Maya с системой MCP](https://github.com/dcc-mcp/dcc-mcp-maya) позволяет связать программу Autodesk Maya с системой DCC-MCP Gateway. С помощью функций поиска и управления процессами вы можете ознакомиться с инструментами, доступными в соединенном экземпляре Maya.

### Есть ли такой инструмент, как Blender MCP?

Да. Официальная интеграция [Blender MCP](https://github.com/dcc-mcp/dcc-mcp-blender) соединяет Blender с той же Gateway и поддерживает общие процессы обнаружения, проверки и контроля рабочих процессов в области DCC-MCP.

### Есть ли такой человек, как Худини, который имеет степень MCP?

Да. Официальная интеграция [Houdini MCP](https://github.com/dcc-mcp/dcc-mcp-houdini) предоставляет репозиторий и специфические реализации для SideFX Houdini.

### Что означает SP MCP?

**SP MCP** – это общепринятая аббревиатура для **Substance Painter MCP**. Официальное название этого инструмента – **Substance 3D Painter MCP**. Информацию о том, как использовать этот инструмент, можно найти на сайте [dcc-mcp-substance3d-painter](https://github.com/dcc-mcp/dcc-mcp-substance3d-painter). Используйте этот репозиторий и платформу DCC-MCP, когда вам необходимо создавать текстуры.

### Как найти инструмент DCC MCP?

`dcc-mcp-cli health` для подтверждения связи с сервером, использование команды `dcc-mcp-cli search --query <intent> --dcc-type <host>` для улучшения процесса поиска, после чего следует перейти к следующему шагу, указанному в `next_step`. Для получения подробностей о установке и совместимости обратитесь к репозитории адаптеров, специфичных для конкретного хоста.
