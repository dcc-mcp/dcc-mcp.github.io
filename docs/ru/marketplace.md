# Поиск Skills и пакетов

На [DCC-MCP Marketplace](https://github.com/dcc-mcp/marketplace) представлены информация о навыках, поставщиках ресурсов, возможностях интеграции с другими сервисами, а также информация о общей инфраструктуре. Выберите нужный DCC-сервис, а затем скопируйте инструкции по настройке или точные команды для работы с CLI-интерфейсом.

Сначала изучите незнакомый пакет. После вашего согласия команда `dcc-mcp-cli marketplace install ... --reload` установит пакет с выбранным идентификатором и перезагрузит приложение. Установка выполняется на вашей машине.
