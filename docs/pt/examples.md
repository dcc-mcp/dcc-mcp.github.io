# Exemplos de adaptadores e instruções

Cada cartão inclui uma saída, o repositório que o possui e um prompt. Um agente que utiliza a [Skill `dcc-mcp`](https://clawhub.ai/loonghao/skills/dcc-mcp) ainda precisa descobrir os ferramentas locais ou os pacotes do Marketplace, e deve perguntar antes de instalar qualquer coisa.

::: info Coleção Oficial de Exposição
<a href="https://dcc-mcp.github.io/showcase/" target="_self">Abra a coleção DCC-MCP Showcase.</a> Para casos completos, as fontes do projeto, os registros de chamadas de ferramentas e as informações sobre licenciamento. Os exemplos de adaptadores abaixo mantêm o escopo das evidências originais; algumas das placas ilustram as funcionalidades dos adaptadores, mas não representam registros de produção ou reprodução nesta sessão.
