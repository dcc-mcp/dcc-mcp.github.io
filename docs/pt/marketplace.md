# Buscar Skills e pacotes

O [DCC-MCP Marketplace](https://github.com/dcc-mcp/marketplace) lista habilidades, fornecedores de recursos, integrações com estúdios e infraestruturas compartilhadas. Selecione um DCC como destino, e então copie o prompt de configuração ou a ordem exata do comando CLI.

This website não instala software. Após aprovar a alteração, `dcc-mcp-cli marketplace install ... --reload` instalará o ID do pacote selecionado e recarregará o DCC. Primeiro, verifique os pacotes desconhecidos.
