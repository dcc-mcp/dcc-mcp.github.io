# Ejemplos de adaptadores e instrucciones

Cada tarjeta incluye una salida, el repositorio que la posee y un prompt. Un agente que utiliza la habilidad [`dcc-mcp`](https://clawhub.ai/loonghao/skills/dcc-mcp) todavía necesita descubrir los herramientas locales o los paquetes del Marketplace, y debe preguntar antes de instalar cualquier cosa.

::: info Colección oficial de muestras
<a href="https://dcc-mcp.github.io/showcase/" target="_self">Abra la colección DCC-MCP Showcase.</a> Para los casos completos, se proporcionan fuentes del proyecto, registros de herramientas utilizadas y información sobre licencias. Los ejemplos de adaptadores que se presentan a continuación mantienen su alcance de evidencia original. Algunas tarjetas ilustran las capacidades de la herramienta, pero no representan registros de producción o reproducción en esta sesión.
:::
