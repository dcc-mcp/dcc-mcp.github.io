# Buscar Skills y paquetes

El [DCC-MCP Marketplace](https://github.com/dcc-mcp/marketplace) enumera las habilidades disponibles, los proveedores de recursos, las integraciones con estudios y la infraestructura compartida. Seleccione un DCC como destino, y luego copie ya sea una instrucción de configuración o el comando CLI exacto.

Comprueba el contenido de los paquetes que no conozcas. Una vez que autorices el cambio, `dcc-mcp-cli marketplace install ... --reload` instala el paquete con el identificador elegido y recarga la aplicación. La instalación se ejecuta en tu equipo.
