- `hunyuan3d.webp`: `dcc-mcp/dcc-ai-hunyuan3d`, `docs/images/dcc-ai-hunyuan3d-showcase.webp`
- `geospatial-city.webp`: `dcc-mcp/dcc-asset-geospatial`, `docs/images/overture-city-data-showcase.webp`
- `maya-architecture.jpg`: `dcc-mcp/dcc-mcp-maya-procedural-architecture`, `docs/showcase/turntable-contact-sheet.jpg`

- `freecad-game-ready-pipeline.webp`: `dcc-mcp/dcc-mcp-freecad`, `docs/images/dcc-mcp-freecad-showcase.webp`; illustrates the same cross-DCC acceptance path from the editable CAD document boundary.
- `cinema4d-typed-scene.webp`: `dcc-mcp/dcc-mcp-cinema4d`, `docs/images/dcc-mcp-cinema4d-showcase.webp`; limited to implemented typed primitives, transforms, inspection, validation, render, and runtime-reported interchange capabilities.
- `comfyui-typed-workflow.webp`: `dcc-mcp/dcc-mcp-comfyui`, `docs/assets/comfyui-workflow-showcase.webp`; limited to the live-validated API-format graph validation, queue submission, bounded wait, normalized status, and artifact URL capabilities.
- `illustrator-typed-vector-workflow.webp`: `dcc-mcp/dcc-mcp-illustrator`, `docs/images/illustrator-showcase.webp`; limited to live-validated typed document, rectangle, path, text, official DOM, save, and SVG/PNG export capabilities.
- `sketchup-typed-modeling.webp`: `dcc-mcp/dcc-mcp-sketchup`, `docs/images/sketchup-showcase.webp`; limited to live-validated typed model inspection, grouped primitives, materials, Tags, scenes, validation, save, and runtime-supported interchange export.
- `touchdesigner-typed-operator-workflow.webp`: `dcc-mcp/dcc-mcp-touchdesigner`, `docs/images/touchdesigner-scripting-showcase.webp`; an illustrative workflow image limited to the implemented typed project, operator, parameter, connection, TOP capture, project-save, delete, and readback boundaries. It is not a TouchDesigner screenshot or host-validation record.
- `cache-inspection-workflow.webp`: `dcc-mcp/dcc-mcp-cache-inspector`, `docs/images/cache-inspection-showcase.webp`; an illustrative OpenAI ImageGen workflow with no third-party source assets, limited to bounded content detection, optional SCF/Blosc decoding, privacy-safe counts, bounds, primitive families, and attribute summaries. It is not a Houdini screenshot or host-validation record.
- `shogun-typed-mocap-workflow.webp`: `dcc-mcp/dcc-mcp-shogun`, `docs/images/shogun-scene-showcase.webp`; illustrative workflow for the 36 fixed typed Scene, file, Timeline, and Offline tools. Newer official SDK surfaces remain capability-gated and the image is not a host-validation record.
- `tiled-typed-map-workflow.webp`: `dcc-mcp/dcc-mcp-tiled`, `docs/images/tiled-showcase.webp`; illustrative workflow limited to the fixed typed Tiled driver, bounded map and tileset authoring, object layers, tile painting, inspection, validation, and conversion.
- `material-maker-typed-material-workflow.webp`: `dcc-mcp/dcc-mcp-material-maker`, `docs/images/material-maker-showcase.webp`; illustrative workflow limited to bounded PTEX inspection, validation, and official CLI export. It does not imply interactive graph authoring.
- `krita-typed-paint-workflow.webp`: `dcc-mcp/dcc-mcp-krita`, `docs/images/krita-showcase.webp`; illustrative workflow limited to the implemented typed document, layer, rectangle fill, save, export, flatten-confirmation, and close boundaries.
- `gimp-typed-image-workflow.webp`: `dcc-mcp/dcc-mcp-gimp`, `docs/images/gimp-showcase.webp`; illustrative workflow limited to the authenticated fixed typed image, layer, save, export, flatten-confirmation, and close boundaries.
- `katana-typed-lookdev-workflow.webp`: `dcc-mcp/dcc-mcp-katana`, `docs/images/katana-showcase.webp`; illustrative workflow limited to the implemented typed main-thread node graph, port, parameter, timeline, inspection, and project-save operations.
- `premiere-typed-edit-workflow.webp`: `dcc-mcp/dcc-mcp-premiere`, `docs/images/premiere-showcase.webp`; illustrative workflow limited to typed project inspection, media import, sequence and timeline authoring, markers, project save, encoder queue submission, and frame export. It does not imply a queued render reached terminal completion.
- `zbrush-fantasy-dragon.png`: `dcc-mcp/dcc-mcp-zbrush`, captured after a typed 5,000,000-face import, 115,364-face ZRemesh, 45-degree turn, and PolyFrame display using the [Artec 3D Fantasy Dragon](https://www.artec3d.com/3d-models/fantasy-dragon) under CC BY 4.0.
- `zbrush-maya-fantasy-dragon.png`: `dcc-mcp/dcc-mcp-maya`, captured through scoped project UI Control after typed verification of the 5,000,000-face source and its 115,364-face Maya wireframe; model attribution remains Artec 3D, CC BY 4.0.
- `wwise/*.wav`: `dcc-mcp/dcc-mcp-wwise`, `showcase/audio/*.wav`; deterministic MIT-licensed audio generated by the owning repository.
