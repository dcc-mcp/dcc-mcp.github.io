# Cloud workflow evidence

`2026-10-01.json` summarizes the frozen cloud worker report supplied to the
documentation task. It records one dots Debian cloud computer, software and
adapter identities, observed workflows, test totals and failure boundaries.
PC8 website checks do not count as cloud DCC tests.

The report archive SHA-256 identifies the source bundle. The private bundle is
not a public download; no private Library URL or unpublished patch payload is
included. Local patch commit IDs identify what was tested, not a published
release or a public pull request. The English and Chinese cloud-agent pages
link this same evidence snapshot.
