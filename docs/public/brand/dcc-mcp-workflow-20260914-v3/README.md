# DCC-MCP v3 workflow illustration sources

Five original ImageGen outputs preserved unchanged, each 1672 × 941 pixels.
They supply the [30-second and 50-second bilingual films](../../videos/dcc-mcp-intro-20260914-v3/README.md).
The films add Remotion framing, typography and motion, then Kdenlive assembly and
audio. WebP posters are frames from the completed movies, not replacements for
these original sources. [Exact prompts and the reference chain](imagegen-provenance.json).

These are **AI-generated interface reconstructions and workflow illustrations**,
not actual screenshots or recordings of the illustrated operations being executed.
They are not benchmarks, permission receipts or audit evidence.
