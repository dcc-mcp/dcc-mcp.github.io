# Skill 및 패키지 검색

[DCC-MCP 마켓플레이스](https://github.com/dcc-mcp/marketplace)에는 스킬, 자산 제공자, 스튜디오와의 통합 기능, 그리고 공유 가능한 인프라가 나열되어 있습니다. 먼저 대상 DCC를 선택한 다음, 설정 지침이나 정확한 CLI 명령어를 복사해 두세요.

이 웹사이트는 소프트웨어를 설치하지 않습니다. 변경 사항을 승인한 후, `dcc-mcp-cli marketplace install ... --reload` 명령어를 사용하여 선택된 패키지를 설치하고 DCC를 다시 로드할 수 있습니다. 먼저, 익숙하지 않은 패키지들을 먼저 확인해보세요.
