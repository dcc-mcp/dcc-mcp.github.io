# AI로 제작 도구 제어하기

이 예시들에서는 공개된 [`dcc-mcp` Skill](https://clawhub.ai/loonghao/skills/dcc-mcp)과 `dcc-mcp-cli`를 사용합니다. 프롬프트는 필요한 결과와 검사 내용을 설명합니다. 에이전트는 연결된 호스트에서 해당 도구의 이름을 찾아냅니다.

AI 에이전트가 실행 중인 창의적인 애플리케이션을 제어할 수 있도록 하려면, 아래의 지침을 참고하여 작업을 수행하고 작동 방식을 결정해야 합니다. 각 지침에는 해당 애플리케이션에 대한 설치 정보, 호환성 정보, 그리고 애플리케이션에 관련된 세부 정보가 포함되어 있습니다.

## 마야 연결의 예시

`dcc-mcp` 스킬을 설치한 다음, [Maya 어댑터](https://github.com/dcc-mcp/dcc-mcp-maya)를 연결해야 합니다. CLI나 어댑터를 추가하기 전에, 현재 설치된 상태를 확인해보세요.

```text
DCC-MCP를 설정하여, 이 머신에서 Maya를 제어할 수 있도록 해야 합니다. 먼저 @loonghao/dcc-mcp 공개된 자습서를 따라 설치하고 실행하세요. 현재의 CLI와 Maya 어댑터를 먼저 확인해보세요. 시스템 상태를 변경하기 전에 반드시 확인해야 합니다. Maya를 열어서 게이트웨이와 실제 Maya 인스턴스를 확인하세요. 단일 읽기 전용 검색을 수행하여 흐름을 파악한 후, 연결된 인스턴스, 사용 가능한 기능, 그리고 다음으로 취할 수 있는 안전한 조치를 보고하세요. 설정하는 동안 현재의 장면을 변경하지 마세요.
```

연결 상태를 확인해 주세요:

```bash
dcc-mcp-cli health
dcc-mcp-cli list
dcc-mcp-cli search --query "inspect Maya scene" --dcc-type maya
```

## 블렌더 연결 예시

[Blender 어댑터](https://github.com/dcc-mcp/dcc-mcp-blender)를 사용하여 동일한 Skill과 CLI를 활용할 수 있습니다. 설치 과정 및 Blender에 특화된 도구들은 여전히 그 리포지토리에 남아 있습니다.

```text
DCC-MCP를 설정하여, 이 머신에서 Blender를 제어할 수 있도록 해야 합니다. 먼저 @loonghao/dcc-mcp라는 공개된 튜토리얼을 따라 설치를 진행하세요. 현재의 CLI와 Blender 어댑터를 먼저 확인해보세요. 시스템 상태를 변경하기 전에 반드시 확인해야 합니다. Blender를 열어서 게이트웨이와 실제 Blender 인스턴스를 확인하세요. 단순히 검색만 수행하고, 연결된 인스턴스, 사용 가능한 기능, 그리고 다음으로 취할 수 있는 조치를 보고하세요. 설정하는 동안 현재의 시나리오를 변경하지 마세요.
```

연결 상태를 확인해 주세요:

```bash
dcc-mcp-cli health
dcc-mcp-cli list
dcc-mcp-cli search --query "inspect Blender scene" --dcc-type blender
```

## Maya에서 무작위로 10개의 구를 어떻게 만들 수 있을까요?

추측된 도구의 이름이 아니라, 실제로 얻어진 결과를 설명해 주세요. 랜덤 시드, 범위, 이름 지정 과정, 그리고 관련된 검사들도 포함시켜 주세요.

```text
dcc-mcp 스킬을 사용하여 내 라이브 Maya 인스턴스에 연결해 주세요. “ai_random_spheres”라는 새로운 그룹을 만들고, 결정론적 시드 값이 42인 10개의 다각형 구체를 생성해 주세요. 각 구체에 고유한 이름을 부여하고, X가 -10에서 10 사이, Y가 0에서 10 사이, Z가 -10에서 10 사이의 무작위 위치에 배치해 주세요. 서로 교차하지 않도록 주의하세요. 기존의 시각적 내용은 삭제하거나 대체하지 마세요. 먼저 Maya 도구들을 사용하여 작업을 진행하고, 반환된 next_step을 모두 따르세요. 그런 다음 최종적으로 생성된 구체들의 개수, 이름, 변환 정보, 그리고 그룹 구성원 정보를 확인해 주세요. 증거를 보여주고, 제가 요청하지 않는 한 시각적 내용을 저장하지 마세요.
```

## 저는 게임을 만들고 싶어요. 하지만 어디서부터 시작해야 할까요?

먼저, 플레이 가능한 루프를 하나 정의합니다. 그런 다음 [Unreal Engine](https://github.com/dcc-mcp/dcc-mcp-unreal), [Unity](https://github.com/dcc-mcp/dcc-mcp-unity), 또는 [Godot](https://github.com/dcc-mcp/dcc-mcp-godot) 중에서 선택할 수 있습니다. 추가적인 자산이 필요한 경우 [Marketplace](/ko/marketplace)를 사용하세요. 사용하기 전에는 각 라이선스가 적용되는지 반드시 확인해야 합니다. [Showcase](/ko/examples)에는 예시가 제공됩니다.

```text
DCC-MCP를 사용하여 작은 규모의 플레이 가능한 게임을 만들어 주세요. 먼저, 사용할 엔진(Unreal, Unity, Godot 중 하나), 대상 플랫폼, 비주얼 스타일, 그리고 한 문장으로 설명할 수 있는 플레이 가능한 루프를 알려주세요. 아이디어를 한 단계 줄여서, 한 번의 승리나 실패 조건만을 가진 게임으로 만들어야 합니다. 연결된 DCC와 엔진들을 인벤토리에 추가하고, 필요한 자산들을 찾아보세요. 패키지를 설치하거나 자산을 다운로드하거나 시스템 상태를 변경하기 전에 반드시 확인해야 합니다. 최소한의 규모로 게임을 만들고, 실행하여 제어 장치와 승/실패 루프가 제대로 작동하는지 확인하세요. 그 후, 프로젝트와 패키지 빌드 경로를 보고하세요. 실행 가능한 버전이 없다면, 완성된 것이라고 주장하지 마세요.
```

## AI를 사용하여 사진을 어떻게 편집할 수 있을까요?

보정, 색상 조정, 마스크 처리, 레이어 관리, 그리고 파일 내보내기 등을 위해 [Photoshop 어댑터](https://github.com/dcc-mcp/dcc-mcp-photoshop)를 사용하세요. 변경해야 할 부분과 그대로 유지해야 할 부분을 명시하세요. 또한, 필요한 출력 형식도 지정해야 합니다.

```text
dcc-mcp 스킬을 사용하여 Photoshop에 연결되어, 이 이미지를 편집하는 데 도와주세요. 먼저, 무엇을 변경해야 하는지, 무엇을 그대로 유지해야 하는지, 참조된 스타일은 무엇인지, 그리고 전달 형식은 어떻게 되는지 확인해야 합니다. 원본 문서를 그대로 유지하고, 새로운 레이어나 조정 레이어, 마스크, 스마트 오브젝트 등을 사용하여 작업을 진행하세요. 하지만 제 허가 없이는 원본을 평평하게 만들거나 덮어쓰지 마세요. Photoshop의 도구들을 활용하여 처음으로 작업을 해보고, 결과물을 요구사항과 비교해보세요. 치수, 색상 모드, 레이어 구조, 그리고 누락된 자산들이 있는지 확인한 후에야, 제가 승인한 후에야 새로운 파일로 내보내세요.
```

## AI를 사용하여 영화를 어떻게 편집하거나 조합할 수 있을까요?

타임라인 편집에는 [Premiere Pro](https://github.com/dcc-mcp/dcc-mcp-premiere)를, 모션 그래픽 및 레이어 기반의 작업에는 [After Effects](https://github.com/dcc-mcp/dcc-mcp-aftereffects)를, 노드 기반의 합성을 위해서는 [Nuke](https://github.com/dcc-mcp/dcc-mcp-nuke)를 사용하세요. 작업을 수행할 때는 해당 작업 흐름을 담당하는 앱을 사용해야 합니다.

```text
dcc-mcp 스킬을 사용하여 이 영화를 편집하거나 합성할 수 있도록 도와주세요. 먼저, 이 작업이 Premiere에서의 타임라인 편집인지, After Effects에서의 모션 그래픽스인지, 아니면 Nuke에서의 노드 합성을 위한 작업인지 확인해야 합니다. 원본 미디어를 파악하고, 해상도, 프레임 속도, 색상 공간, 오디오 요구 사항, 전달 대상 등을 확인해야 합니다. 원본 파일을 보존한 상태에서 새로운 프로젝트나 컴포지션을 생성합니다. 필요한 도구들을 찾아서 사용하고, 하나의 샷이나 시퀀스를 완성한 후, 미리보기를 렌더링합니다. 누락된 미디어나 프레임 범위를 확인한 후, 프로젝트와 미리보기의 경로를 보고해야 합니다. 코덱이나 플러그인을 설치하기 전에 반드시 확인해야 합니다. 또한, 미디어를 다시 연결하거나 최종 렌더링을 시작하기 전에도 반드시 확인해야 합니다.
```

## AI를 사용하여 시각 효과를 어떻게 만들 수 있을까요?

프로시저리얼 지오메트리와 시뮬레이션에는 [Houdini](https://github.com/dcc-mcp/dcc-mcp-houdini)를 사용합니다. 장면의 합성을 위해서는 Nuke나 After Effects를 사용합니다. 실시간 효과를 위해서는 [Unreal Engine](https://github.com/dcc-mcp/dcc-mcp-unreal)를 사용합니다. 테스트 장면을 만들기 전에, 각각의 작업에 적합한 애플리케이션을 반드시 확인해야 합니다.

```text
dcc-mcp 스킬을 사용하여 시각 효과를 만들어 주세요. 먼저, 효과의 세부 사항을 알려주세요. 효과가 Houdini 시뮬레이션에서 사용될지, Nuke나 After Effects로 처리될지, 아니면 Unreal 실시간 VFX를 통해 처리될지 결정해야 합니다. 연결된 호스트들을 확인하고, 필요한 도구들을 선택하세요. 최소한의 설정을 제안해 주세요. 제어장치는 편집 가능하게 유지하고, 소스 플레이트와 장면을 보존해야 합니다. 필요할 때만 캐싱이나 렌더링을 해야 합니다. 미리보기를 생성하고, 타이밍, 크기, 색상 공간, 결여된 종속 항목 등을 확인해야 합니다. 또한, 캐시와 미리보기의 경로를 보고해야 합니다. 자산을 다운로드하거나 플러그인을 설치하거나 비싼 시뮬레이션이나 최종 렌더링을 시작하기 전에 반드시 확인해야 합니다.
```

## 왜 스크립트를 요청하는 대신 DCC-MCP를 사용해야 할까요?

스크립트는 일회성 작업에 있어서는 여전히 유용합니다. DCC-MCP는 동일한 워크플로우가 반복될 때, 입력된 데이터의 검증, 요청 ID의 관리, 인스턴스의 라우팅, 진단 기능 등을 제공합니다. 운영 방법에 대해서는 [For Agents](/ko/agents)를 참조하십시오.
