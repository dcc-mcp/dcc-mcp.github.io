# Adapterbeispiele und Beispielaufträge

Jede Karte enthält eine Ausgabe, das dazugehörige Repository sowie einen Prompt. Ein Agent, der die [`dcc-mcp` Fähigkeit](https://clawhub.ai/loonghao/skills/dcc-mcp) verwendet, muss zunächst die lokalen Tools oder Pakete im Marketplace finden und bevor er etwas installiert, muss er dies erst um Erlaubnis bitten.

::: info Offizielle Kollektion
<a href="https://dcc-mcp.github.io/showcase/" target="_self">Öffnen Sie die DCC-MCP Showcase-Sammlung.</a> Für vollständige Fälle, Projektquellen, Tool-Call-Protokolle sowie Lizenzinformationen. Die untenstehenden Beispiele für Adapter behalten ihre ursprüngliche Reichweite bei. Einige Karten zeigen die Funktionen der Adapter an – sie stellen jedoch keine Aufzeichnungen über die Herstellung oder Reproduktion dieser Karten dar.
:::
