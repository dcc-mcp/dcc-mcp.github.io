# Skills und Pakete suchen

Der [DCC-MCP Marketplace](https://github.com/dcc-mcp/marketplace) listet Fähigkeiten, Anbieter von Ressourcen, Integrationen mit Studios sowie gemeinsam genutzte Infrastrukturen auf. Wählen Sie einen Ziel-DCC aus und kopieren Sie anschließend entweder eine Anleitung zur Einrichtung oder den exakten Befehl über die CLI.

Diese Website installiert keine Software. Nachdem Sie die Änderung genehmigt haben, wird der ausgewählte Paket-Id mit `dcc-mcp-cli marketplace install ... --reload` installiert. Anschließend wird das DCC neu geladen. Überprüfen Sie zunächst die unbekannten Pakete.
