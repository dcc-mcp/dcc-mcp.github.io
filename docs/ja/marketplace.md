# Skill とパッケージを探す

[DCC-MCPマーケットプレイス](https://github.com/dcc-mcp/marketplace)には、スキル、アセットプロバイダー、スタジオとの連携方法、共有可能なインフラストラクチャーなどが掲載されています。まず、対象のDCCを選択し、セットアップ用のプロンプトや、正確なCLIコマンドをコピーしてください。

このウェブサイトでは、ソフトウェアをインストールすることはありません。変更内容を承認した後、`dcc-mcp-cli marketplace install ... --reload`というコマンドを実行することで、選択されたパッケージがインストールされ、DCCが再読み込みされます。まずは、見知らぬパッケージについて確認してください。
