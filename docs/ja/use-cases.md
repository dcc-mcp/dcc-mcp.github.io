# 制作ソフトを AI で操作する

これらの例では、公開されている[`dcc-mcp`スキル](https://clawhub.ai/loonghao/skills/dcc-mcp)や`dcc-mcp-cli`が使用されています。プロンプトには、必要とされる結果やチェック項目が記載されており、エージェントは接続されたホストからツールの名前を特定します。

AIエージェントが、実際に動作するクリエイティブなアプリケーションを操作できるようにするためには、以下のガイドに従ってください。このガイドでは、具体的なタスクや操作手順が説明されています。各ガイドには、アダプターリポジトリへのリンクもあります。このリポジトリでは、アプリケーションのインストール方法や互換性、その他の詳細情報が管理されています。

## マヤのつながりの例

`dcc-mcp`スキルをインストールし、[Mayaアダプター](https://github.com/dcc-mcp/dcc-mcp-maya)を接続してください。CLIやアダプターを追加する前に、既存のインストール状況を確認してください。

```text
このマシンでMayaを制御できるように、DCC-MCPを設定してください。また、@loonghao/dcc-mcpという公式ガイドラインに従ってインストールを行ってください。まずは、現在のCLIやMayaアダプターを確認してください。システムの状態を変更する前には必ず確認してください。Mayaを開いて、ゲートウェイや実際のMayaインスタンスを確認してください。1回だけ読み取り専用の検索を行い、その流れを説明してください。そして、接続されているインスタンスや利用可能な機能、次に行うべき安全な操作について報告してください。設定中は、現在のシーンを変更しないでください。
```

以下の項目を確認してください：

```bash
dcc-mcp-cli health
dcc-mcp-cli list
dcc-mcp-cli search --query "inspect Maya scene" --dcc-type maya
```

## ブレンダー接続の例

[Blenderアダプター](https://github.com/dcc-mcp/dcc-mcp-blender)を使用して、同じスキルやCLIを利用できます。インストールやBlenderに特有のツールは、そのリポジトリに残ります。

```text
DCC-MCPを設定して、このマシン上でBlenderを制御できるようにしましょう。インストールを行い、@loonghao/dcc-mcpのスキルを実行してください。まず、現在のCLIとBlenderアダプターを確認してください。システムの状態を変更する前には必ず確認してください。Blenderを開いて、ゲートウェイとライブBlenderインスタンスを確認してください。1回だけ読み取り専用の検索を行い、その流れを説明し、接続されているインスタンスや利用可能な機能、次に行うべきBlenderの操作について報告してください。設定中は、現在のシーンを変更しないでください。
```

以下の項目を確認してください：

```bash
dcc-mcp-cli health
dcc-mcp-cli list
dcc-mcp-cli search --query "inspect Blender scene" --dcc-type blender
```

## Mayaで、10個のランダムな球体をどのように作成するか？

推測されるツールの名前ではなく、実際に得られた結果を記述してください。ランダムシード、境界条件、命名方法、およびチェック項目も含めてください。

```text
dcc-mcpスキルを使って、私のライブMayaインスタンスに接続してください。ai_random_spheresという名前の新しいグループを作成し、確定的なシード値42を使用して、正確に10個のポリゴンで構成された球体を作成します。各球体に固有の名前を付け、X軸が-10から10、Y軸が0から10、Z軸が-10から10の範囲内のランダムな位置に配置します。ただし、互いに交差しないようにしてください。既存のシーンデータを削除したり、置き換えたりしないでください。最初にMayaのツールを使って作業を行い、次に返されるnext_stepの指示に従ってください。最終的に、球体の数、名前、変換情報、グループメンバーシップを確認してください。証拠を見せてください。私が指示しない限り、シーンを保存しないでください。
```

## ゲームを作りたいです。では、どこから始めればいいでしょうか？

1つのプレイ可能なループを定義した後、[Unreal Engine](https://github.com/dcc-mcp/dcc-mcp-unreal)、[Unity](https://github.com/dcc-mcp/dcc-mcp-unity)、または[Godot](https://github.com/dcc-mcp/dcc-mcp-godot)のいずれかを選択します。オプションのアセットについては、[Marketplace](/ja/marketplace)を利用してください。使用する前には、各ライセンス内容を確認してください。[Showcase](/ja/examples)には、例示的なプロンプトが含まれています。

```text
DCC-MCPを使って、少しのゲームを作るのを手伝ってください。まず、使用するエンジン（Unreal、Unity、またはGodot）、対象となるプラットフォーム、ビジュアルスタイル、そして1文で表されるゲームのループ構造を教えてください。アイデアを1レベル、1回の勝敗条件にまで簡略化してください。接続されているDCCやエンジンを確認し、必要なライセンスを持つアセットを公式のマーケットプレイスで探してください。パッケージをインストールしたり、アセットをダウンロードしたり、システムの状態を変更する前に、必ず確認してください。実行可能なゲームを作り、コントロールや勝敗のループ構造を確認し、結果を記録し、プロジェクトとパッケージのビルドパスを報告してください。実行可能なゲームができていない状態では、完成したとは言えません。
```

## AIを使って写真をどのように編集するのでしょうか？

修復や色調の調整、マスク処理、レイヤーの操作、出力形式の設定などを行うには、「[Photoshopアダプター](https://github.com/dcc-mcp/dcc-mcp-photoshop)」を使用してください。何を変更する必要があるか、何を変更しない必要があるか、そして必要な出力フォーマットは何かを明確にしましょう。

```text
dcc-mcpスキルを使ってPhotoshopに接続し、この画像の編集を手伝ってください。まず、何が変更されるべきか、何が変更しないべきかを決めてください。また、参照用の見た目や配信形式も確認してください。元のドキュメントを保持しつつ、新しいレイヤーや調整レイヤー、マスク、スマートオブジェクトなどを使用してください。私の承認なしに、ソース画像を平らにしたり上書きしたりしてはいけません。Photoshopのツールを使って、まずは基本的な編集を行ってください。結果を説明に合わせて確認し、サイズや色モード、レイヤーの構造、不足しているアセットなどを確認してください。その後、私が承認した後にのみ、新しいファイル形式にエクスポートしてください。
```

## AIを使って、どのように映画を編集したり、合成したりするのでしょうか？

タイムラインの編集には[Premiere Pro](https://github.com/dcc-mcp/dcc-mcp-premiere)を、モーショングラフィックやレイヤベースの編集には[After Effects](https://github.com/dcc-mcp/dcc-mcp-aftereffects)を、ノードベースのコンポジションには[Nuke](https://github.com/dcc-mcp/dcc-mcp-nuke)を使用してください。作業を行う際は、ワークフローを持つアプリケーションを使い続けてください。

```text
dcc-mcpスキルを使って、この映像を編集したり、合成したりするのを手伝ってください。まず、この作業がPremiereでのタイムライン編集か、After Effectsでのモーショングラフィック処理か、またはNukeでのノード合成処理かを確認してください。ソースメディアの情報を把握し、解像度、フレームレート、カラースペース、音声の要件、配信先などを確認してください。ソースファイルを保持しつつ、新しいプロジェクトやシーケンス、コンポジットを作成します。適切なツールを使って、1つのショットやシーケンスを完成させ、プレビューを表示します。不足しているメディアやフレーム範囲を確認し、プロジェクトとプレビューのパスを報告してください。コーデックやプラグインをインストールする前に、必ず確認してください。メディアを再リンクしたり、最終的なレンダリングを開始する前にも、必ず確認してください。
```

## AIを使って、どのように視覚効果を作成することができるのでしょうか？

プロシージャルジオメトリやシミュレーションには[Houdini](https://github.com/dcc-mcp/dcc-mcp-houdini)を、ショットのコンポジットにはNukeやAfter Effectsを、リアルタイムエフェクトには[Unreal Engine](https://github.com/dcc-mcp/dcc-mcp-unreal)を使用してください。テストショットを作成する前に、どのアプリケーションがそのショットを管理しているかを確認してください。

```text
dcc-mcpスキルを使って、視覚効果を作成する手助けをしてください。まず、ショットの概要、参照情報、持続時間、カメラの設定、配信形式などを指定してください。また、その効果はHoudiniシミュレーションで実行されるのか、NukeやAfter Effectsのコンポジションで実行されるのか、それともUnreal EngineのリアルタイムVFXで実行されるのかも確認してください。接続されているホストを調べ、適切なツールを選択し、最小限の設定を行ってください。コントロールは編集可能にしておき、ソースプレートやシーンを保持しておきます。必要に応じてのみキャッシュやレンダリングを行い、プレビューを生成してください。タイミング、スケール、色空間、欠けている依存関係などを確認し、シーン、キャッシュ、プレビューのパスを報告してください。アセットをダウンロードしたり、プラグインをインストールしたり、高コストなシミュレーションや最終レンダリングを開始する前には、必ず確認してください。
```

## なぜ、DCC-MCPを使うのではなく、スクリプトを要求するのでしょうか？

スクリプトは、一度限りの作業には有効です。DCC-MCPでは、同じワークフローを繰り返す必要がある場合に、タイプ検出、論理的検証、インスタンスのルーティング、リクエストIDの管理、診断機能が追加されます。[For Agents](/ja/agents)を参照して、操作手順を確認してください。
