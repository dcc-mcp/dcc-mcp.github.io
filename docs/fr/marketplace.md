# Rechercher des Skills et des paquets

Le [DCC-MCP Marketplace](https://github.com/dcc-mcp/marketplace) propose une liste des compétences disponibles, des fournisseurs d’actifs, des intégrations avec les studios, ainsi que des infrastructures partagées. Choisissez un DCC cible, puis copiez soit un commande de configuration, soit le commande CLI exacte.

Examinez d’abord les paquets que vous ne connaissez pas. Une fois votre accord donné, `dcc-mcp-cli marketplace install ... --reload` installe sur votre poste le paquet choisi et recharge l’application.
