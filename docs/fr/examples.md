# Exemples d’adaptateurs et consignes

Chaque carte comprend une sortie, le répertoire qui la gère, ainsi qu’un prompt. Un agent utilisant la compétence [`dcc-mcp`](https://clawhub.ai/loonghao/skills/dcc-mcp) doit toujours découvrir les outils locaux ou les packages du Marketplace avant de pouvoir installer quoi que ce soit.

::: info Collection officielle de présentation
<a href="https://dcc-mcp.github.io/showcase/" target="_self">Ouvrez la collection DCC-MCP Showcase →</a> Pour les cas complets, les sources de projet, les enregistrements des appels aux outils, ainsi que les informations relatives aux licences. Les exemples d’adaptation ci-dessous conservent leur champ d’application original. Certaines cartes illustrent les capacités des différents outils, mais ne représentent pas des données relatives à la production ou à la reproduction de ces outils lors de cette session.
:::
